# 作品卡片图标来源

- `chrome-translate.webp`：复用 `ALVIN-YANG/chrome-translate` 的 `public/icons/128.png`，对应插件 manifest 中的正式图标；仅缩放并转换格式。
- `senix.svg` / `senix.webp`：沿用 `ALVIN-YANG/senix` 的公开 README `assets/readme/hero.svg` 中三柱标识与配色；管理后台也使用这一标识。SVG 保留为可编辑来源。
- `ay-skills.svg` / `ay-skills.webp`：作品页使用的技能卡片标识，表达独立、可复用的技能与验证完成；原项目没有现成图标。这不是对 AY Skills 仓库品牌资源的替换。SVG 保留为可编辑来源。

以上 WebP 均为 192×192，沿用现有作品卡片的 48×48 显示尺寸。其他已上架应用与 ChimeBuddy 图标保持原样。
