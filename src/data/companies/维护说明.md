# AI 公司目录维护

栏目采用轻量目录：有 AI 产品或服务、有官网、有公开产品或可信名册活动记录即可收录。覆盖大模型、Agent、AI 编程、生成工具、基础设施、语音技术和行业应用。不再要求任务完成率、商业前景、团队或融资的逐家公司调查，不生成前景排名。

## 数据与来源

- `seed.json`：首次整理的基础名单。名称、官网、地区/城市、方向、简介、直接来源及公开产品读取日期保存于此。增加公司时只补这些基础字段，产品归到公司，不为每个产品创建重复条目。
- `sources.json`：来源白名单及自动/参考用途。YC 使用 yc-oss 的非官方 JSON 镜像，前端引用 YC 原始公司档案；只取 Active、有官网和 AI 标签的公司。优先上游 Top Company、招聘状态和团队人数，限制为 35 家以控制规模，不将此顺序写成前景排名。
- `directory.json`：基础名单与来源条目合并后的发布目录，以 ID 和官网域名去重。杭州是国内子集；杭州团队可独立标记，城市未知时不猜。
- `sync-state.json`：名单来源的上次成功日期、错误和官方 PDF 匹配记录。失败不覆盖旧数据和旧日期，也不把抓取日期当备案日期。
- `hangzhou-audit.json`：2026-10-15 一次性官方名单比对快照。保留来源地址、PDF SHA-256、扫描与比对条数、原始主体/产品/序号/PDF 页码，以及收录映射或暂不收录原因；方法页直接展示，月度同步不改写此快照。
- 国家网信办汇总页的最新 PDF 自动读取，仅匹配已整理公司的主体别名，增加直接备案来源。PDF 通过 Python `pypdf==6.10.0` 提取文本，不调用模型。没有官网映射的陌生主体不自动上架。
- 浙江网信图片公告、浙江省经信厅四类名单是参考来源，尚未自动接入；页面明确显示“人工补充”。旧备案或地方名单不能证明公司近期活跃。

基础名单的公开产品页只证明首次整理时有产品入口，不能当作实测或持续经营证明。基础字段和活动依据日期不在每次运行时统一刷新；超过一年未复核的基础资料需人工补充，不能凭网站存在断言当前活跃。每家公司在卡片及详情页显示直接来源，来源原文、中文简介及日期分别保留。

## 杭州补充规则

杭州覆盖大模型、Agent、数据基础设施、AI 安全、视觉、语音、智能硬件与行业 AI 应用；成熟企业只要提供公开 AI 产品或服务，也可收录。只在内部使用 AI 的普通企业不纳入。产品证据与杭州归属证据都要保存：前者来自官方产品页，后者来自官方公司介绍、联系方式、注册主体或服务政策；同一页面可以同时提供两项证据。

官网明确杭州总部或杭州注册主体时填写 `city: "杭州"`。只确认杭州办公团队时使用 `hangzhouTeam: true`，不推断总部。杭州客户、参展地点、创始人籍贯、投资方或历史活动不能证明当前杭州归属。公司、品牌与产品仍按现有规则去重，不拆分产品来增加数量。

2026-10-14 补充 31 家，目录共 108 家，国内 54 家，其中杭州 40 家（含 2 家标注杭州团队）。补充来源均为企业官网、官方文档或官方服务政策；新条目保存在基础名单中。此次未新增自动来源、逐家公司抓取或监控，常规月度同步请求量保持不变。

2026-10-15 按官方名单补充 99 家，目录共 207 家，国内 153 家，杭州分类 140 家（含 7 家标注杭州公司或团队）。科大讯飞原在国内目录，本次补充浙江讯飞主体的杭州团队标记，因此杭州数量比新增公司数多增加 1 家。比对范围如下：

- 浙江省经信厅正式公布的 2024、2025 年人工智能应用场景、标杆企业、服务商、产品四类名单，分别完整读取 179、178 条，逐项比对其中杭州 85、97 条。使用正式公布的签章 PDF，不用公示名单替代。
- 国家网信办汇总页截至 2026 年 8 月的全部 13 期附件，共读取 1,843 条，逐项比对浙江 109 条。历史附件分期增补，不能只读最后一期便声称完整覆盖。
- 浙江网信 2026-09-02、09-23 两则新增公告，分别比对 3、13 条。国家名单仅注明浙江省，另核对杭州归属；明确杭州以外的主体单列。

合计保留 307 条逐项记录，包含重复上榜的主体。已确认官网、公开 AI 产品和杭州归属的合并到目录；63 个主体暂未确认全部所需信息，保留原始记录与缺项，不当作“不符合”。名单中的内部应用、高校/实验室等非公司主体、杭州以外的主体分别说明。此快照只表示上述名单范围的比对完成，不代表覆盖杭州所有企业或所有专项名册。不以产品拆条、猜测域名或推断杭州总部凑数。

新增公司和来源写入基础名单，后续同步保留；没有新增长期官网探测、图片识别、历史附件重抓或模型调用。官方来源失效时寻找同一正式文件的官方存储地址，保留文件哈希供核对。

## 同步与发布

每月 1 日北京时间 08:30，由 `.github/workflows/ai-companies.yml` 在 GitHub Actions 同步名单。没有每日或每周变化监控，不逐个读取公司新闻，不生成动态与商业分析，不配置任何模型密钥。

`npm run companies:sync` 读取名单和最新官方附件；`npm run companies:check` 只校验目录、不联网。普通运行常规请求为 3 次：YC JSON、国家网信办汇总页、最新 PDF。某来源失败时保留其缓存，其他成功来源照常更新，Actions 报告未完成；不以名册短暂缺失删除公司。明确非 Active 时退出 YC 自动名单。

本机执行 PDF 同步需 Python 中安装 pypdf；可通过 `COMPANY_PYTHON` 指定已有解释器。CI 安装固定版本。简介不反复调用模型翻译或改写；初始中文整理后固定，新增条目可保留来源原文。备案是主体与服务的公开记录，不是经营或前景评价。

历史 `catalog.json`、`archive.json`、`updates.json`、`monitor.json` 仅保留旧资料，不再同步。既有公司链接保留，重新进入目录的旧公司可展开历史深度档案；`/companies/changes/` 改为历史动态，不显示待核实本周状态。逐家公司分析脚本和模型连通性测试已移除。

发布前执行 `node --test tests/company-directory.test.mjs tests/company-observer.test.mjs tests/company-coverage.test.mjs`、`npm run companies:check`、`npm run fonts:update`、`npm run build`，浏览器检查地区、方向、搜索、空结果、来源、比对记录、旧档案和手机布局。仅提交本模块、必要字体与导航变化，保留其他用户改动。推送 main 后核对 Vercel 线上页面。
