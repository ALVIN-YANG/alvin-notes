## 本期主线

这一周最清楚的变化不在模型能力，而在编码代理的工程边界被逐条写进版本说明和事故报告。OpenClaw 连续三个版本都在处理密钥与认证，v2026.10.10 让 Git 备份覆盖 PostgreSQL 导出并剔除插件凭据、webhook token 和凭据 blob，v2026.11.1 又修掉配置保存失败覆盖密钥、关闭 Tailscale 暴露后 Gateway 认证失效两个问题。这类改动说明代理类工具默认持有大量凭据，一次保存失败就可能变成泄露。

另一条线是代理与外部系统的身份问题。Cloudflare 连发两篇，一篇给站点所有者提供识别和控制个人代理访问的能力，一篇指出代理代用户行动时服务器只看到剥离了用户身份的中介。Claude Code 被报告会把用户邮箱地址发给访问的网站，社区讨论量很高，同类的“Don't Ask Again”配置还在公开 GitHub 文件里暴露了密码。身份与凭据正在成为代理落地的实际阻塞点，而不是提示词质量。

基础设施侧也在收紧。AWS 大额承诺容量基本售罄到 2027 年，部分 2028 年已分配，按需和 Bedrock 仍留有余量，这会影响需要弹性扩容的推理服务选型。OpenAI 一边收购 Pierre Computer Company 补 Codex 的代码理解与审查工具，一边公开 Pando 这个为 Codex 规模设计的 Git 兼容后端，编码代理的配套基础设施正在被单独建设。

## 01 编码代理的版本与凭据处理

### [OpenClaw v2026.10.10 备份默认脱敏](https://github.com/openclaw/openclaw/releases/tag/v2026.10.10)

`一手` · `GitHub Release` · `11 月 3 日`

该版本让经过密钥脱敏的 Git 备份覆盖 PostgreSQL 导出，并剔除已识别的捆绑插件凭据、webhook token 和凭据 blob。对自建 OpenClaw 并做定期备份的团队，这意味着备份产物本身不再是明文凭据仓库，但仍需确认自定义插件写入的字段是否在识别范围内。

### [OpenClaw v2026.11.1 修复配置保存与 Gateway 认证](https://github.com/openclaw/openclaw/releases/tag/v2026.11.1)

`一手` · `GitHub Release` · `11 月 7 日`

该版本修掉两个 Mac 端问题，配置保存失败时不再覆盖已有密钥，关闭 Tailscale 暴露后 Gateway 认证保持完整。前者对应的是磁盘写入失败这类低频但后果严重的情况，后者关系到关闭外网暴露后本地访问是否仍受保护，升级后值得回归一次远程访问路径。

### [Claude Code 被报告向访问网站发送邮箱地址](https://github.com/anthropics/claude-code/issues/107757)

`社区` · `Hacker News AI` · `11 月 6 日`

GitHub issue 指出 Claude Code 会把用户邮箱地址发送给其访问的网站，该条目在 Hacker News 获得 674 点。对在代理中执行网页抓取或调试的团队，这属于身份信息外泄面，需要在网络出口侧确认实际请求头内容，而不是只看工具文档。

### [Claude Code 的“Don't Ask Again”在 1,122 个公开 GitHub 文件中暴露密码](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again)

`社区` · `Hacker News AI` · `11 月 8 日`

安全厂商 Apiiro 统计到 1,122 个公开 GitHub 文件因该配置项泄露密码。这是使用习惯与默认行为叠加的结果，团队应把代理的免确认配置纳入提交前扫描，并检查历史提交是否已带出凭据。

## 02 代理身份与访问控制

### [Cloudflare 为站点所有者提供个人代理的可见性与控制](https://blog.cloudflare.com/personal-agents-visibility-control/)

`一手` · `Cloudflare Blog` · `11 月 4 日`

Cloudflare 推出面向站点所有者的能力，用于区分自动化与人类流量并管理个人代理访问。对依赖代理抓取或下单的服务，站点侧的策略会直接改变成功率，需要提前确认自己的代理流量会被如何归类。

### [Cloudflare 提出可信代理委托问题](https://blog.cloudflare.com/trusted-agent-delegation/)

`一手` · `Cloudflare Blog` · `11 月 5 日`

文章指出代理代数百万用户行动时，服务器看到的是剥离了用户可见性的中介，并提出识别、允许和管理这类自动化流量的协作方案。这为需要向第三方证明“这是代表某用户”的代理提供了方向，但方案仍在协作阶段，短期内更现实的做法是在自有链路里保留可审计的委托凭据。

### [OpenAI 扩大安全漏洞赏金并引入报告质量与优先级奖励](https://openai.com/index/rewarding-defenders-with-bigger-bug-bounties)

`一手` · `OpenAI 官方` · `11 月 2 日`

OpenAI 提高安全漏洞赏金，并新增报告质量、忠诚度和优先级活动奖金。对做安全研究的独立研究者，奖励结构变化会影响投入方向，值得对照新规则评估报告写法与目标选择。

## 03 编码代理背后的基础设施

### [OpenAI 公开为 Codex 规模设计的 Git 后端 Pando](https://openai.com/index/scaling-git-at-openai)

`一手` · `OpenAI 官方` · `11 月 2 日`

OpenAI 介绍 Pando，一个为 Codex 带来的开发规模而设计的 Git 兼容后端。代理高频提交和分支操作会放大传统 Git 服务的压力，自建代码平台的团队可以据此评估仓库服务的瓶颈位置。

### [OpenAI 收购 Pierre Computer Company](https://openai.com/index/openai-to-acquire-pierre)

`一手` · `OpenAI 官方` · `11 月 4 日`

OpenAI 宣布收购 Pierre Computer Company，用于扩展 Codex 在代码构建、理解和审查方面的工具。媒体转述提到该公司的库已在为 Codex 提供支持，交易与 Pando 结合指向同一方向，即编码代理的代码基础设施被单独建设。

### [OpenCode v2.2.6 支持共享 MCP 连接](https://github.com/anomalyco/opencode/releases/tag/v2.2.6)

`一手` · `GitHub Release` · `11 月 8 日`

该版本允许对 MCP server 开启连接池，在相同配置的多个项目间共享一条连接，从而减少进程数量并加快启动。对同时开多个仓库的开发者，这直接降低本地资源占用，但共享连接也意味着一个项目的异常可能影响其他项目，需要观察隔离表现。

## 04 推理与数据侧的容量和可观测性

### [AWS 大额承诺容量基本售罄至 2027 年](https://www.infoq.com/news/2026/11/aws-capacity-sold-out/)

`资讯` · `InfoQ AI/ML` · `11 月 1 日`

Amazon CEO Andy Jassy 表示 AWS 的大额承诺云容量基本售罄到 2027 年，部分 2028 年容量已分配，公司继续为按需、EC2 和 Bedrock 保留余量。从业者讨论中提到按需容量获取困难，需要弹性扩容的推理服务应提前确认配额与备选区域。

### [Claude Platform 在 Databricks MLflow 中支持原生 OpenTelemetry 可观测性](https://www.databricks.com/blog/claude-platform-now-supports-native-opentelemetry-observability-databricks-mlflow)

`一手` · `Databricks Blog` · `11 月 3 日`

Databricks 宣布 Claude Platform 在 MLflow 中支持原生 OpenTelemetry 可观测性。文章点出的问题是代理可能给出看似合理却漏掉关键发现的答案，或反复读取同一来源，这类行为需要链路级追踪才能定位，接入后应优先验证工具调用与重试的可见性。

### [Databricks 介绍用 Lakebase 分支做 CI/CD 的实践](https://www.databricks.com/blog/lakebase-branching-cicd-lessons-100-pr-databases)

`一手` · `Databricks Blog` · `10 月 31 日`

文章以 100 个 PR 数据库的经验讲 Lakebase 分支用于 CI/CD，起点问题是针对生产数据测试不应超过 30 分钟。对需要真实数据形态做集成测试的团队，分支式数据库把环境准备从小时级压到分钟级，但成本与清理策略仍需按 PR 数量核算。

## 下周观察

1. Claude Code 邮箱地址外发与“Don't Ask Again”泄露两起问题是否出现官方修复版本，可验证信号是 claude-code 仓库对应 issue 关闭并附带版本号，或发布说明中出现请求头与配置存储的变更条目。
2. OpenClaw 的密钥脱敏是否扩展到更多导出格式，可验证信号是后续 Release 说明中列出新增覆盖的备份类型或插件字段。
3. AWS 按需容量紧张是否影响 Bedrock 的实际可用性，可验证信号是官方状态页或配额文档出现区域级调整，以及社区是否报告新的容量申请等待时间。
