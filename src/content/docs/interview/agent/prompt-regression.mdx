## 比较完整行为而非措辞

检查任务结果、工具选择、参数、调用次数、副作用、成本和时延。模型输出有随机性，对关键任务多次运行并记录分布。候选变更先离线验证，再在受控范围上线；保留回滚版本。

### Prompt 只是改了几个字，还需要评测吗？

文字变更可能改变工具选择或让某项规则被忽略。验证范围按影响面选择，小改动可跑相关子集，但安全和关键写操作应保留固定回归项。
