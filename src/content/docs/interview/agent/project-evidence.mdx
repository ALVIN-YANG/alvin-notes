## 一个指标要能经得住追问

教学例：“混合检索比纯向量更好”应说明文档版本、问题来源、正确证据、K 值和对比条件；只改检索策略，检查召回改善是否传到最终答案。如果分块、模型和评测集一起换了，就不能把全部收益归给混合检索。

完成率以达成业务目标为分子，以纳入评测的任务为分母；排除样本及原因要说明。延迟给分布和测量起终点，成本计入重试与工具。线上规模、离线实验和个人 Demo 的结果不能互相替代。

### 项目没上线，还能讲吗？

可以。明确它是个人项目或离线验证，讲真实实现、难点和实验；没有用户或生产证据，就不编造用户规模和线上收益。使用开源项目时说清复用部分、自己的变化，以及这些变化为什么必要。

### Agent 写代码，个人贡献怎么说？

说明自己定义的目标、权限、架构取舍与验收标准，以及 Agent 完成的执行工作。是否亲手逐行编码，不等于是否理解系统；能解释失败机制并核对结果，才有证据支撑技术责任。
