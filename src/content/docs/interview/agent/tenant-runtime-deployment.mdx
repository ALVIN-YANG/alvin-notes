## 逻辑隔离与计算隔离分别设计

数据库、记忆、缓存、事件流和附件按租户及运行标识划分，执行资源配置配额。受控共享进程避免跨会话全局变量；独立沙箱限制文件、网络和凭据。长任务迁移需持久状态，粘性会话不能代替恢复。

### 共享进程怎样验证没有串数据？

并行运行不同用户的相似任务，测试标识伪造、取消、异常、缓存和复用 Worker 等路径。内存占用和任务积压也按租户监控，避免一个用户影响全部服务。
