Q 是查询，K 是用于匹配的键，V 是被聚合的值。自注意力中，同一序列的表示分别线性投影得到 Q、K、V；交叉注意力中，Q 与 K、V 可以来自不同序列。缩放点积注意力为 `softmax(QKᵀ / √dₖ + mask)V`。

因果掩码把未来位置的分数设为负无穷，使其 softmax 权重为 0；当前位置仍可关注自身和历史位置。填充掩码处理的是补齐位置，两者用途不同。

## 解释形状与计算量

单头自注意力的序列长度为 n、头维度为 dₖ 时，分数矩阵为 n×n。多头关注不同投影子空间，拼接后再投影。全注意力的分数部分随序列长度平方增长，但整层还包含投影和前馈网络，不能只按 n² 估算全部耗时。

### Next Token Prediction 为什么必须屏蔽未来？

训练输入包含目标后续文本，若允许看到未来 Token 会泄漏答案。推理逐步生成，历史 K、V 可缓存；KV 容量与推理优化见 AI Infra 对应题。
