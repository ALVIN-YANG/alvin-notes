沙箱通过文件、网络、系统调用、凭据和资源限制，约束模型生成代码的影响范围。容器是隔离的一种手段，通常共享宿主内核，不能据此承诺不会逃逸；运行不可信代码时，要按威胁模型选择并验证隔离机制。

## 按任务授予最小能力

使用专用工作区、非特权身份、只读基础文件系统及 CPU、内存、进程数和运行时限。不授予特权容器权限，不挂载宿主 Docker socket 或无关宿主目录，否则可能绕开原本的边界。网络采用明确目的地规则，业务密钥不进入代码环境。产物导出检查路径、大小和类型，失败任务及时回收资源。

### 把执行命令写进黑名单够吗？

不够，命令组合、解释器和网络都可能绕过字符串限制。安全边界由运行环境与授权代理执行，命令规则只是补充；测试越界文件访问、资源耗尽和网络绕过。
