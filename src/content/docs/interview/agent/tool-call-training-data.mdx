训练数据不仅包含正确工具与参数，还需要无需调用、无工具可用、澄清、错误反馈和多步依赖样本。先判断是工具描述问题、协议适配问题还是模型能力不足，再决定是否训练。

## 保持调用与结果的协议一致

样本保留用户需求、工具定义、调用标识、参数、结果和最终回答，使用目标模型的消息格式。检查参数类型、业务约束及实际可执行性，数据集按任务和工具家族划分，避免近重复泄漏。

### 训练后怎样证明不是只记住了工具名？

测试未见参数、改名工具、相似工具、无权限及无答案场景。分别测工具选择、参数正确、拒绝与端到端成功率；Schema 合法不代表业务正确。
