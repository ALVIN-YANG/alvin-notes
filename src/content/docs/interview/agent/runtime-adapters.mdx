## 统一事件，保留原始语义

标准事件至少记录 run_id、序号、事件类型、状态和时间；保留底层事件用于排障。适配器转换配置、工具和权限时做验证，测试正常运行、错误、取消、断流与恢复。摘要交接和原生状态恢复应分别暴露。

### 怎样判断换 Runtime 没有退化？

同一任务集对比成功率、工具副作用、产物和成本，验证状态转换及恢复路径。只跑通一条对话，无法说明不同 Runtime 的能力兼容。
