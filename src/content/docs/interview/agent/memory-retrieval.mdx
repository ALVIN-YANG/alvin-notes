## 区分事实、偏好和任务经验

用户偏好可以跨会话使用，订单状态通常需要实时查询，某次失败经验要限定工具和版本。冲突事实保留版本并选择有效项，不把旧记忆重复追加到每轮上下文。被删除或撤回授权的记忆不能继续通过缓存命中。

### 怎样评估召回是否污染了任务？

比较无记忆、正确记忆、过期记忆和其他用户相似记忆下的结果，检查错误引用与越权。记录检索候选、实际注入的记忆及答案引用，配合移除某条记忆的对照实验判断影响。模型自称使用了某条记忆，不足以证明其内部推理过程；也不能只测检索命中率。
