Tokenizer 把文本映射成模型使用的 Token；一个字、词或代码标识符不一定对应一个 Token。词表与切分规则影响长度、成本和代码片段表示，预算应使用所选模型的实际计数。

## 切片先保留语义结构

代码按函数、类和依赖组织，再检查 Token 上限；文本按章节、句子与表格处理。仅按字符数估算可能低估中文、特殊符号或长标识符的用量。比较模型时同时核对可用窗口和工具 Schema 开销。

### 增大词表是否一定提高代码能力？

不一定。词表影响表示与训练分布，能力还取决于数据、模型和后训练。不能仅从 Token 更少推断代码更正确；应实测补全、工具参数和成本。
