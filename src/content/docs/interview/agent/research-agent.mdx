## 让证据跟随结论传递

子任务输出事实、推断和未核实事项，优先原始论文或官方资料。协调者维护覆盖表，检查缺少的主题、过期材料和同一来源的重复转载。失败分支可重试或缩小范围，最终报告明确缺口。

### 并行调研一定更快吗？

只有可独立工作才容易获益。重复检索、上下文交接和汇总会增加成本，用同一问题比较单 Agent 与多 Agent 的覆盖、准确度、耗时和用量。
