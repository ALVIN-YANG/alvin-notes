## 协调代码所有权与集成顺序

任务契约包含允许文件、接口、验收条件和截止时间。每个 Agent 在独立工作区提交可审查改动，协调者检查重叠、接口兼容与依赖。测试运行在沙箱，凭据由提交代理持有；PR 记录真实验证结果。

### 多个 Agent 改了同一文件怎么办？

先明确负责人或序列化集成，冲突时按需求重新判断语义，不能只自动选择一侧。合并后重新验证集成行为，单个分支测试通过不证明组合正确。
