倒排索引记录每个词出现在哪些文档中；BM25 根据词频、词的区分度和文档长度给结果打分。它适合产品编号、错误码和专有名词；向量检索更擅长找语义近似但字面不同的表达。

## 词频增加不是无限加分

BM25 对词频采用饱和处理，并对文档长度做归一化，避免长文仅因重复关键词获得优势。中文分词、字段权重和停用词会影响效果；同一个检索器换分词器后也应重跑评测。

### 直接把 BM25 分数与向量相似度相加行吗？

两者分数尺度不同，未经校准相加没有稳定含义。可以先采用基于名次的融合，再按标注集调权重和重排。混合检索的完整链路见对应题。
