工具结果要关联模型发出的调用标识，才能区分同一轮的多个调用。工具名相同也可能参数不同；只按消息到达顺序拼接，会把结果绑定到错误请求。

```mermaid
flowchart TB
  A["模型接口返回调用标识"] --> B["并行执行工具"]
  B["并行执行工具"] --> C["按标识归并结果"]
  C["按标识归并结果"] --> D["回传当前运行"]
```

## 保留调用与结果的完整配对

记录模型接口返回的调用 ID、工具版本、参数、执行状态和结果。并行结果按标识归并，并遵循所用接口对消息顺序的要求；失败也要返回对应标识的错误结果。

模型接口的工具调用 ID、MCP 的 JSON-RPC 请求 ID、业务幂等键承担不同职责。Host 在转发时维护它们的映射，不能假设三者相同。调用 ID 用于配对结果，业务幂等键用于识别同一次业务操作及其重试；还要检查调用 ID 在当前运行中的冲突。

### 重复或迟到的结果怎么办？

先判断调用是否属于当前运行和尝试，按执行记录去重。运行已经取消或切换版本时，迟到结果可以入审计，但不能更新新的任务状态。
