## 从行为覆盖到真实执行

提取正常流程、边界、失败、权限、状态迁移和组合约束，把每项关联到需求。测试数据与外部依赖隔离，验证测试确实能捕获错误，而不是只匹配当前实现。生成结果记录覆盖缺口和待确认事项。

### 生成很多测试能证明质量好吗？

数量容易被近重复放大。用需求覆盖、缺陷检出、误报、维护成本和执行稳定性评价，审查断言是否具有业务意义；关键验收仍由负责人确认。
