## 异步链路仍然需要容量控制

使用有界并发、超时和取消，避免一次启动所有任务压垮下游。同步文件操作或重计算会阻塞事件循环。对线程、进程与异步方案分别测吞吐、P95、内存和资源回收；Python 版本及 GIL 配置会影响结论。

### 取消异步任务后，远程调用一定停止吗？

不一定，客户端取消只说明本地等待终止。远程可能已经执行，需要调用标识和状态查询；写任务不能因等待取消就直接重复提交。
