## 统一比较对象和评价标准

要求各角色输出结论、依据、假设与缺口。协调者对齐时间、数据范围和目标，再做确定性验证或补充检索。设定争议轮次和成本上限；无法收敛时保留分歧及待核实事项。

### 增加更多 Agent 投票会更可靠吗？

同一模型和同一错误上下文会产生相关错误。独立证据、不同验证方法和明确裁决规则通常比单纯增加人数更有用；用冲突样本检验改善幅度。
