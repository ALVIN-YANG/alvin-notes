## 不同字段采用不同合并语义

追加事件可以按唯一事件 ID 合并，预算扣减必须原子执行，最终任务状态需要合法转换。版本冲突后重新读取并计算，不能无条件重试旧值。长时间工具执行不要持有数据库事务锁。

### 把所有结果拼成列表就没有冲突了吗？

列表仍可能重复、乱序或包含取消后的结果。每条结果关联任务、尝试和版本；归并时校验身份、顺序与有效性，业务终态只能由指定协调者发布。
