Bitmap 在有界且可映射为位下标的集合中直接记录成员，映射不冲突时可以精确判断；布隆过滤器把一个元素映射到多个位，节省空间，但不同元素可能共用这些位，导致把不存在的元素判断为“可能存在”。

<InterviewVisual src="/images/interview/cards/agent-bloom-filter-bitmap.webp" alt="布隆过滤器和 Bitmap 有什么区别？误判率受哪些因素影响？图解。Bitmap：下标直接记录；Bloom：多个哈希位共享；不存在 → 可能误判存在；可能存在还要查真实数据。" />

标准布隆过滤器在正确插入、没有删除或数据丢失等前提下，不应把已插入元素判断为不存在。误判率取决于位数组大小、已插入元素数和哈希函数数量；哈希函数越多并不总是越好，还增加计算成本。

过滤器回答“可能有”后仍要查询真实数据源。普通布隆过滤器不能直接清掉某个元素对应的位，因为这些位可能被其他元素共用；需要删除时考虑带计数等合适结构，并处理重建与更新一致性。
