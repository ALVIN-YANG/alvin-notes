## 产物必须能定位到原始素材

保留时间戳、片段范围、素材版本及模型版本，选择采样策略时评测短事件漏检。任务按解码、识别、标注与审核分阶段恢复；回调接收端用事件唯一约束和原子状态更新去重，产物用稳定标识发布。仅携带事件 ID，不会自动保证幂等，发布到外部系统时仍需核对其重试语义。

### 只抽几帧能保证理解完整视频吗？

不能，短暂事件、音频含义和跨镜头关系可能丢失。按业务目标选择密度和模态，对漏检与时延做取舍，最终结果明确覆盖范围。
