## 沿请求链收集证据

关联 Trace、错误率、P95 时延、连接池、数据库和下游状态，对照变更时间。限制查询范围避免排查加重故障。每个假设说明证据与下一步，操作前检查目标环境和当前版本，操作后验证真实恢复。

### 没有找到根因，能否先做应急操作？

可以按已批准的 Runbook 执行限流或降级，但应说明依据和影响，并监控恢复指标。没有证据时不伪称已定位根因，无法确认权限的变更转交值班人员。
