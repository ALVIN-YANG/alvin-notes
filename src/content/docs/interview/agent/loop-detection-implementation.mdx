## 记录语义状态而不是原始字符串

对调用参数做稳定序列化，对结果保存状态或内容哈希，识别连续相同调用与结果、状态往返和持续无新证据。合法轮询有等待间隔和截止时间。检测触发后可澄清、调整策略或退出，禁止无限自我修复。

### 写一个检测器要测哪些案例？

相同工具不同页码应继续，相同参数但结果正在变化未必停止，相同状态反复往返应触发。还要处理参数字段顺序、时间戳等噪声和取消后的迟到结果。
