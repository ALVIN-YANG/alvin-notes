IoC（控制反转）把对象的创建、组装和生命周期管理交给容器。依赖注入是实现它的一种方式：对象声明自己需要什么，由容器提供，不必自己创建或查找依赖。Spring 管理的对象称为 Bean。

例如，订单服务需要支付接口。如果在服务内部直接创建某个支付实现，更换支付渠道或测试替身时，往往要改服务本身。改成通过构造器接收支付接口，服务只处理订单逻辑，外部决定提供哪个实现。构造器注入也能让必需的依赖一目了然。

依赖注入本身不要求 Spring，手工组装对象也可以做到。Spring 的价值在于统一管理大量对象及其关系；它不会自动让单例 Bean 变得线程安全。把用户身份或订单状态保存在单例的可变字段里，仍可能串数据。
