## 怎么判断题目归属

按解答需要的主要机制归类。例如 Python 并发归工程基础，任务表与消息队列的一致性归系统设计，线上超时排查归可靠性与运维，Agent 规划归 AI 应用。题目中的 Agent、Python、客服、运维、性能和安全等关联，保留为技术、场景或关注点标签。

RAG 关注怎样检索并生成有依据的回答；数据与知识工程关注解析、入库、索引、版本和更新。规划与多 Agent 关注怎样分解和执行任务；Harness 运行工程关注循环、预算、状态、中断恢复和执行控制。模型训练与推理解释计算机制，可靠性与运维关注这些服务上线后的观测与故障。

二级专题参考了[极客时间 AI 面试题库的公开目录](https://time.geekbang.org/space/wiki/AI_Interview?section=1.2)，按本库能力边界重新组织。框架名称作为技术标签，框架选型放在相关架构专题；难度用于独立筛选。

## 怎么练习和排序

先理解机制，再解释失败条件，最后用一个具体场景说明取舍和验证方法。练习系统设计时说明目标、负载、数据与失败边界；练习 Agent 时核对证据、工具、权限、状态与结果；练习模型时明确模型、硬件、精度、序列长度与并发。

模块内，有对应原帖的题按近 90 天独立作者与公司的出现频次排列；没有原帖的题标为题单收录或知识补充，再按现有学习顺序排列。热度、难度与能力分类是不同维度，频次高不等于更难。来源、时间窗口和去重规则见[面经来源与热度口径](/interview/agent-sources/)。
