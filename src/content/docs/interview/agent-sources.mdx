## 怎么去重和排序

同一考点的不同问法只保留一个答案。例如 BM25、向量检索、RRF 和 Cross-Encoder 的相关追问归入“混合检索与重排”；ReAct 与先规划再执行的追问归入“规划与重新规划”。框架选型与节点状态合并为一题，避免为了数量拆出同义题。

每个作者在同一家公司对同一题只计一次，一篇帖子中的多次追问也只计一次。排序依次比较记录数、公司覆盖数、最近发帖日期；完全相同时按题号稳定排列。页面显示原帖与考察方向，可用公司名搜索题目。

只有原帖正文明确涉及的考点才计入；搜索推荐、评论、转载合集和广告题单不增加次数。题库原有但本次没有对应记录的内容标成“工程补充”，放在面经题之后，记录数为零不代表不会考。AI Infra 保持学习顺序。

帖子浏览量、点赞量不用于题目排序。发帖日期不等于面试日期；这个样本排序可以辅助安排练习，但没有全网热榜的统计代表性。
