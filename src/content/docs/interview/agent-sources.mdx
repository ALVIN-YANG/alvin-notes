## 近期热度怎么计算

近 90 天指 **2026-07-17 至 2026-10-14**，按发帖日期计算，发帖日期不一定是面试日期。

同主题的不同问法归并为一道题；同一作者在同一家公司对同一主题只计一次，一篇帖子里的多个追问也只计一次。多个轮次可以提供不同考点，但不会对同一题重复加分。内容相同却署名不同、模板文章、广告、合集和无法回到原帖的转载不增加频次。

排序依次比较近期原帖数、近期公司覆盖数、全部原帖数、全部公司覆盖数、最近发帖日期，最后用题单收录数和现有学习顺序区分同分题。外部题单不增加原帖数；其公司标签也不作为本站核对过的出题公司。分类不改变原帖频次；无对应原帖的题按现有机制学习顺序排列。

分题以答案是否需要不同机制为准。例如工具调用循环、工具设计与并发调度分别讲协议执行、接口契约与依赖控制；ReAct 与 Plan-Execute 的多种问法则归并。BM25 的评分机制与混合检索链路分开，多种同义“Agent 是什么”不拆成多题。

点赞和浏览量不用于排序。本站样本频次适合安排练习，不能称为全网热榜；为具体岗位准备时，再用 JD、岗位类型与公司筛选。
