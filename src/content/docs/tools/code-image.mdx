把代码排成图片，用于技术文章、演示或聊天分享。粘贴代码、选择背景，然后下载 PNG。无需登录，代码在浏览器本地处理。

## 怎样生成代码图片

1. 在上方代码窗口中，替换示例代码。保留缩进和换行，便于阅读。
2. 在“标题”中填写文件名或说明，也可以留空。
3. 选择背景颜色，确认预览中的代码和排版。
4. 点击“下载 PNG”，保存图片后插入文章或演示文稿。

例如，把下面的代码粘贴到窗口，标题填 `add.js`，就能生成带文件名和代码的图片。工具只负责排版，不会执行这段代码。

```javascript
function add(a, b) {
  return a + b;
}
```

## 图片尺寸与使用限制

导出的 PNG 固定为 **800px 宽**，高度随代码行数增加。长行会在导出时折行，因此预览与导出图片的换行位置可能不同。手机屏幕较窄时，可以横向滚动查看预览，导出宽度仍为 800px。

工具提供基础语法着色，当前没有语言选择器。不同语言的着色可能不完整，也不会检查代码能否编译或运行。分享较长代码时，可以先提取与问题相关的片段，再分成几张图片。

## 代码会上传吗

代码、标题和图片生成都在浏览器中处理，不会上传到服务端。页面及字体加载仍需要网络；这里的“本地处理”不代表整个网站离线运行。

## 图片和原始代码怎样一起分享

图片适合展示排版，原始文本更方便读者复制、搜索和修改。在博客中展示代码时，建议保留文本代码块，再按需附上图片；在聊天中讨论问题时，也可以同时发送代码文本。
