## 访问与统计

本站使用 Vercel 托管和 Vercel Web Analytics 统计访问情况。服务提供方会处理提供网站和保障安全所需的网络请求信息；访问统计包括页面地址、来源、设备、浏览器和大致地区等信息，用于了解文章阅读情况和改进网站。

Vercel Web Analytics 不使用 Cookie 来识别访客。具体数据处理方式见 [Vercel Web Analytics 隐私说明](https://vercel.com/docs/analytics/privacy-policy)和 [Vercel 隐私政策](https://vercel.com/legal/privacy-policy)。文章页显示的浏览次数是汇总统计。

## 本地存储与朗读

AI 概念卡片使用浏览器的本地存储保存学习进度。站点主题等阅读设置也可能保存在你的浏览器中。本站不会将概念卡片的学习进度上传到服务器；清除本地站点数据会删除这些记录。

朗读使用浏览器或操作系统提供的语音合成功能。语音是否在线处理取决于你选择的声音及设备设置。

## 评论

文章评论由 giscus 和 GitHub Discussions 提供。发表评论需要登录 GitHub，评论内容、公开用户名及头像会显示在站点和对应的 GitHub 讨论中。请不要在公开评论中填写地址、电话、证件号码等私人信息。

你可以通过 GitHub 管理自己的评论。相关服务的数据处理方式见 [giscus 隐私说明](https://github.com/giscus/giscus/blob/main/PRIVACY-POLICY.md)和 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。

## Google 广告与 Cookie

本站已接入 Google AdSense，广告须经 Google 审核通过后展示。Google 及其广告合作伙伴可能使用 Cookie、网络信标、IP 地址或其他标识符，处理访问和广告互动信息，用于投放广告、防止欺诈、控制展示频次和衡量效果。第三方可能在你的浏览器中放置或读取 Cookie。

个性化广告可能依据你对本站及其他网站的访问情况。详情见 [Google 如何使用合作伙伴网站或应用的数据](https://policies.google.com/technologies/partner-sites)和 [Google 广告 Cookie 说明](https://policies.google.com/technologies/ads)。你可以在 [Google 我的广告中心](https://myadcenter.google.com/)管理个性化广告，也可以通过浏览器设置管理 Cookie。

加载广告的文章页面为欧洲经济区、英国和瑞士的访客提供 Google 广告隐私选择消息。你可以选择“不同意”，或通过页面上的“隐私和 Cookie 设置”入口重新调整选择。拒绝个性化广告不一定会停止所有广告。
